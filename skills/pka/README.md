# Partial Knowable Algebra Skills

This folder packages Partial Knowable Algebra (PKA) workflows as reusable agent skills.

PKA skills must preserve three boundaries:

1. **Partial stays partial.** Unknown state is never silently coerced into certainty.
2. **Known means governed.** A system may treat only its declared/versioned rules as knowable invariants.
3. **Cases drive promotion.** A rule, equation, or workflow graduates only after a defined case provides evidence for it.

## Skills

- [`bapedi-cultural-game-hub`](./bapedi-cultural-game-hub/SKILL.md) — apply PKA to a governed Cultural Game Hub using Telemetry AI evidence, parser reduction, contract-ledger state transitions, minimal Identic AI state passes, APWA adaptation, and Memory Receipts.
